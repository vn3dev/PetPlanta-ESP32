# Fontes históricas de animação

Esta pasta guarda versões recebidas durante o desenvolvimento das animações.
Ela não é usada pelo Flask nem pelo navegador em execução.

- `pet-planta/`: fonte original e a versão intermediária `pet-planta2/`.
- `pet-planta-v7/`: fonte da versão final usada para atualizar o modo festa.

Os assets ativos ficam em `../static/pet-planta/`.
